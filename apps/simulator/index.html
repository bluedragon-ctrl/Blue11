Blue-11

A PDP-11-style computer to program in assembly: screen, keyboard, speaker, console
keyboard → program
Read-only memory at 160000–167777. Call JSR PC, @#DRAWCH (mode 0) or JSR PC, @#DRAWC1 (mode 1) with R0 = the character, R1 = where it goes, R2 = the colour.
The speaker over the last frame (20000 cycles): up is out, down is in. The program moves it with SNDCS bit 0, or the tone generator every SNDDIV cycles. Measure a half period against the ruler.
